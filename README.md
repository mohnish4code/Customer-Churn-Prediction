# Customer Churn Prediction using Deep Learning

A simple Deep Learning project that predicts whether a customer is likely to leave a company's service (churn) based on customer information.

---

## 📌 Project Overview

Customer churn prediction helps businesses identify customers who are likely to stop using their services. This allows companies to take preventive actions and improve customer retention.

This project is built using **TensorFlow/Keras** and a Deep Neural Network (DNN).

---

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- TensorFlow / Keras
- Matplotlib

---

## 📊 Dataset

- Kaggle Bank Churn Dataset
- Target Variable:
  - **0** → Customer Stays
  - **1** → Customer Churns

---

## ⚙️ Workflow

- Load the dataset
- Perform data preprocessing
- Encode categorical features
- Scale numerical features
- Split the data into training and testing sets
- Build a Deep Neural Network
- Train the model
- Evaluate the model
- Make predictions
